# Computer Components Design

计算机组成原理与数字逻辑课程实验合集。

## 已实现模块

### Arithmetic Unit

- 补码加法器
- 四位补码运算器
- 二进制补码加法器

### Data Processing Unit

- 移位器

### Control Unit

- 节拍脉冲发生器
- 时序控制电路

### Memory System

- RAM扩展
- ROM扩展

### Display Unit

- 七段译码器

## 开发工具

- Verilog HDL
- Vivado

## 项目目标

从硬件层面理解计算机核心部件的实现原理。
